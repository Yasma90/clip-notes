# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-09-04

### Added
- First public release of clip-notes!
- **Markdown Capture**: Paste HTML from any source and it auto-converts to Markdown.
- **Local Synthesis**: Extract key points into bullets using a local algorithm (no external API).
- **Smart Storage**: Notes are saved locally in the Documents folder, organized by date and topic.
- **Auto-Topic Detection**: Automatically suggests topics based on note content.
- **Navigation**: Browse notes by topic or hierarchical date (year > month > day).
- **Search & Filters**: Search by title, content, or tags.
- **Live Preview**: Resizable split-pane preview.
- **English UI**: All application interfaces and documentation are now in English.
- **License**: Added MIT License for open-source distribution.
